# Implementation plan

1. Milestone 0: Architecture, threat model, data flow, API contract, and learning map.
2. Milestone 1: Monorepo setup, TypeScript, linting, formatting, shared types, and Docker Compose.
3. Milestone 2: Backend foundation, configuration validation, database connection, logging, errors, health checks, and OpenAPI.
4. Milestone 3: Authentication, refresh-token rotation, RBAC, and tests.
5. Milestone 4: Workspace and document metadata APIs, authorization, upload validation, and tests.
6. Milestone 5: Document ingestion, chunking, embeddings, Qdrant indexing, and job tracking.
7. Milestone 6: Retrieval service, metadata filtering, score thresholds, citations, and evaluation scripts.
8. Milestone 7: RAG generation, provider abstraction, grounding, injection defenses, and streaming chat.
9. Milestone 8: Frontend foundation with protected routes and dashboard views.
10. Milestone 9: Streaming chat UI, search, history, and feedback.
11. Milestone 10: Admin analytics and operational metrics.
12. Milestone 11: Unit, integration, frontend tests, seed data, and evaluation scripts.
13. Milestone 12: Docker hardening, GitHub Actions, deployment guide, and final README updates.
14. Milestone 13: Security audit and final verification.

## Current repository status

The workspace currently includes a working monorepo scaffold, TypeScript tooling, Docker Compose base services, backend auth, and frontend shell pages.
